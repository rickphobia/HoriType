# HoriType
A typing game for laptop/pc beginners to get used to typing 


## Feature 
In this game, all you need is keyboard.
You have to type 'Start' to start the game, 'Settings' to change the settings

- `start` – normal game
- `super` – start with every power up ready
- `settings` – arrow keys (or type `speed 7`, `health 5`, `rate fast`) to change word speed, max health and how often words appear

Type a word and press Enter to kill it before it touches the red line on the right.
